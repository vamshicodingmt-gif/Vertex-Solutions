Privacy policy

How this website handles information.

Effective date: 7 November 2026.

Information entered into the enquiry form

The enquiry form on this static website prepares a message in your browser. It does not submit the form fields to a Vertex Solutions application server. When clipboard access is available, the page copies the message so you can paste it into a separate communication channel. You decide whether and where to send that message.

Website request data

The hosting provider may process standard technical request information to deliver, protect and operate the website, such as request time, requested resource, browser details and network information. The handling of this data is subject to the hosting provider's own terms and privacy notices.

Cookies and analytics

This website's current source does not intentionally set advertising or analytics cookies. If analytics, embedded services, advertising tools or additional forms are added later, this policy should be reviewed and updated before those features go live.

External websites

Links to government and other external resources open websites operated by third parties. Their privacy practices are governed by their own policies.

Updates

This policy describes the current static website implementation and may change when site features change. The effective date above indicates the latest revision represented by this page.

For general enquiries, use the contact page and follow the instructions shown there.
